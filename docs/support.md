# Support

InspectStack is MIT-licensed source. There is no paid support window and no commercial license tier.

## Where to ask

- Product defects and questions: [GitHub issues](https://github.com/waleed-mirza/inspectStack/issues).
- Security reports: [SECURITY.md](../SECURITY.md). Do not file a public issue for a secret or a tenant leak until the maintainer has replied.

## What a useful report includes

1. Product version from `VERSION`.
2. Install profile: native local or managed cloud, with Node and pnpm versions.
3. Steps to reproduce, expected vs actual.
4. Logs with secrets removed.
5. The runner support bundle when the issue is field capture or sync (`/app/run/[id]/recovery`).

Do not send service-role keys, `.env.local`, or personal evidence photos.

## Not included

- Custom features, extra report layouts, data migration, or cloud-account administration.
- Industry certification. Configurable audit trails are not a compliance sign-off.
- Guaranteed response times.
