How to read these

  1. Numbered orange badges are callouts, not UI.
  2. Buttons with links are the clickable path. Dead boxes are future chrome.
  3. Copy uses product language: Offline, Queued, Synced, Fail — not protocol names.
  4. Empty, error, permission, and offline variants sit in the right rail or footer of each screen.
