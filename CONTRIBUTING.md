# Contributing

InspectStack is MIT-licensed. Issues and pull requests are welcome.

1. Read [docs/quick-start.md](docs/quick-start.md) and run the app locally.
2. Keep changes inside the existing modules. Do not add paid APIs.
3. Match the surrounding TypeScript and the field-ticket UI in `packages/ui`.
4. Do not commit `.env.local`, service-role keys, live project refs, or personal data.

Open a pull request against `main` with what changed and how you checked it.
